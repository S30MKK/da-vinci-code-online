# 达芬奇密码 · 多人联机数字版

网页版《达芬奇密码》桌游：电脑和手机打开同一个网址即可玩，无需安装任何软件，手机/电脑可进同一房间互通对局。

## 功能

- 房间对局：6 位房间码，2–4 人实时对战，服务端权威判定规则
- 抽牌选堆：抽牌时可选黑牌堆 / 白牌堆（策略性更强）
- AI 机器人：房主可向空位添加机器人（基于公开信息推理）
- 观战：观战者进房围观，房主可随时切换「看到暗牌 / 仅公开信息」
- 回放：每局结束后可逐步回放（上一步 / 下一步 / 自动播放）
- 聊天：自由文字 + 预设表情与快捷短语
- 断线重连：掉线后 90 秒内凭「昵称 + 房间码」回到原座位，超时判负
- 战绩系统：按昵称记录总局数、胜 / 负、胜率、连胜（AI 不计入）
- 评分系统：每局 0–100 综合分（0.7 技术 + 0.3 运气）+ 长期积分（Elo 风格）
- 响应式：电脑大屏围桌式布局，手机竖屏自动改为纵向堆叠

## 本地运行

需要 Node.js 18+（开发环境为 Node 24）。**零依赖，无需 npm install**。

```bash
node server.js
```

然后浏览器打开 <http://localhost:3000>。端口可用环境变量 `PORT` 覆盖，如：

```bash
PORT=8080 node server.js
```

## 运行测试

```bash
node --test
```

覆盖：牌序规则、Joker、猜牌概率估算、评分与积分公式、战绩持久化、完整对局端到端、断线重连、观战切换。

## 公网部署（Render / Railway）

单实例即可，无数据库：

1. 把本目录推送到 GitHub（`stats.json` 已加入 `.gitignore`，不会提交）。
2. Render：New → Web Service → 选择仓库。Build Command 留空，Start Command 填 `node server.js`，环境变量 `PORT` 由平台自动注入。
3. Railway：New Project → Deploy from GitHub，启动命令 `node server.js`。
4. 平台会提供 HTTPS 域名，手机浏览器实时通信使用 wss，开箱即用。

注意：免费实例休眠后首次访问会慢几秒；房间与回放存在内存中，重启会丢失，战绩与积分保存在 `stats.json`（重启不丢，建议定期备份）。

## 玩法规则

- 每回合先抽一张牌：**选择抽黑牌堆或白牌堆**（黑 Joker 在黑堆、白 Joker 在白堆），摸到的牌对自己明牌并自动按升序排入牌行；自己回合内可随时调整 Joker 位置
- 再猜一名对手的牌：报数字或报「Joker」；被猜中的牌翻开并全场可见（明牌），猜对后可选择继续猜或停手；猜错：翻开本回合新抽到的牌（牌堆已空则自选一张抛弃）
- 牌序：黑 0 < 白 0 < 黑 1 < 白 1 < … < 黑 11 < 白 11；Joker 是百搭，可放任意位置，猜牌时可报「Joker」，猜中即移除、猜错翻自己一张`n- 所有牌的黑/白颜色公开可见（数字保密），抽牌仍可选黑堆或白堆
- 所有牌都被翻开即出局，最后仍持有暗牌者获胜

## 战绩备份（防止免费服务器重置丢失）

服务器端 `stats.json` 是权威数据，免费实例重启/重建可能被清空。推荐备份方案：

- 网页端：大厅战绩面板有「⬇ 下载战绩备份」和「⬆ 上传恢复」按钮；每局结束后浏览器还会自动在本地保存一份（localStorage）。
- 电脑端脚本（零依赖）：在项目目录执行
  ```bash
  node tools/sync-stats.js pull https://你的域名    # 下载备份到 stats-backup.json
  node tools/sync-stats.js push https://你的域名    # 把备份上传回服务器
  ```
- 建议用 Windows 任务计划（或 crontab）每 30 分钟自动执行一次 `pull`；服务器重置后用 `push` 一键恢复。
- 也可把 `stats-backup.json` 同步到网盘/坚果云，多一层保障。

## 项目结构

```
server.js            零依赖 Node 服务端（静态托管 + WebSocket + 游戏引擎 + 战绩/评分）
public/index.html    单页应用（大厅 / 房间 / 对局桌 / 回放）
public/css/styles.css
public/js/client.js  前端逻辑
public/manifest.webmanifest / icon.svg   PWA「添加到主屏幕」
tests/               单元与端到端测试
stats.json           运行时生成：战绩与积分（原子写入）
```
